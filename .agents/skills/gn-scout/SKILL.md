# GN Scout — גילוי מקומות חדשים ל-gonorth.co.il

## מטרה

מחפש מקומות חדשים בצפון ישראל שמתאימים לקטגוריות האתר, מסנן כפילויות ומקומות סגורים, ומוסיף אותם לרשימת ההמתנה לאישור.

## סדר עבודה (חובה לפי הסדר)

```
1. הגדרת קריטריוני חיפוש  →  2. חיפוש Google Places  →  3. סינון כפילויות  →  4. בדיקת פעילות  →  5. הצגת דוח סיור  →  6. אישור משתמש  →  7. הוספה לרשימה
```

|--------|------------|---------|

## שלב 4 — בדיקת פעילות נוספת (לאחר סינון)

עבור כל מועמד שעבר את שלב 3, בצע בדיקה כפולה:

### 4א — בדיקה מה-API (אוטומטית)

- `business_status` חייב להיות `"OPERATIONAL"`
- אם חסר — המשך עם סימון "לא ודא"

### 4ב — בדיקת אתר רשמי (מומלץ)

אם יש `website` מה-API — שלוף ובדוק שהאתר מגיב:

```bash
ssh gonorth "curl -s -o /dev/null -w '%{http_code}' --max-time 10 'WEBSITE_URL'"
```

- `200` / `301` / `302` — האתר פעיל
- `404` / `410` / timeout — חשוד, סמן בדוח

### 4ג — WebSearch (אם יש ספק)

בצע חיפוש בגוגל עם שם המקום + "סגור" / "נסגר" / "closed" כדי לוודא שלא סגר לאחרונה:

```
[שם המקום] סגור 2024 OR 2025 OR 2026
```

אם מוצאים תוצאות שמציינות סגירה — **דחה** את המקום.

## שלב 7 — הוספה ל-places-to-add.md

עבור כל מקום שאושר, הוסף שורה לטבלה בקובץ `/Users/navisror/dev/gonorth/places-to-add.md`.

### פורמט השורה

```
| [מספר רץ] | [שם המקום] | [קטגוריה בעברית] | ממתין |
```

### כללי הוספה

- **מספר רץ** — המשך מהמספר הגבוה ביותר הקיים בטבלה
- **שם** — בעברית, כפי שמופיע בגוגל / באתר הרשמי
- **קטגוריה** — לפי הטבלה הבאה:

| קטגוריה באתר | מה לכתוב בקובץ |
|---|---|
| אטרקציות וטבע | `אטרקציות` |
| לינה וצימרים | `לינה` |
| אוכל ושתייה | `אוכל` |
| סיורים ופעילויות | `סיורים ופעילויות` |
| שני סוגים | `אטרקציות / אוכל` (כמו יקב) |

- **סטטוס** — תמיד `ממתין` (לא `הוסף`)

### עדכון הקובץ

השתמש בכלי Edit להוסיף את השורות **לפני שורת `---` הסוגרת את הטבלה**:

```bash

```

```

...

כדי להוסיף אותם לאתר, השתמש בסקיל gn-place או הרץ /next-place
```
