# source-command-next-place

Use this skill when the user asks to run the migrated source command `next-place`.

## Command Template

קרא את הקובץ `/Users/navisror/dev/gonorth/places-to-add.md` ובצע את הפעולות הבאות בסדר:

## שלב 1 — סטטוס הרשימה

הצג סיכום קצר של מצב התור:

- כמה מקומות כבר **הוסף** (בוצע)
- כמה מקומות **ממתין** (עדיין בתור)
- סך הכול

פורמט:

```
תור הוספת מקומות — gonorth.co.il
✓ הוסף: X מקומות
◌ ממתין: Y מקומות
סה"כ: Z מקומות
```

## שלב 2 — המקום הבא

מצא את **הרשומה הראשונה** (הכי קטנה בטור #) שהסטטוס שלה הוא `ממתין`.

אם **אין מקומות ממתינים** — הודע שהרשימה הושלמה ועצור.

אחרת, הצג:

```
המקום הבא להוספה:
  # [מספר] — [שם המקום]
  קטגוריה: [קטגוריה]
```

## שלב 3 — הפעלת תהליך gn-place

קרא את סקיל ה-gn-place מהקובץ `.agents/skills/gn-place/SKILL.md` ובצע את כל שלביו עבור המקום שזוהה בשלב 2:

1. **בדיקת כפילות** — חיפוש באתר ובקובץ
2. **מחקר** — איסוף כתובת, GPS, טלפון, אתר, שעות
3. **Google Places API** — דירוג ותמונה (מהשרת בלבד)
4. **בניית תוכן** — Approval Card בעברית
5. **אישור משתמש** — עצור וחכה לאישור
6. **פרסום** — לאחר אישור בלבד
7. **עדכון סטטוס** — שנה `ממתין` → `הוסף` בקובץ `places-to-add.md`

**חשוב:** אל תדלג על אף שלב. אל תפרסם בלי אישור מפורש.
