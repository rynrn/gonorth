# #75 — היגיינת אישורים בהוראות ובסריקה

תאריך: 06.10.2026. כרטיס: https://github.com/rynrn/gonorth/issues/75; משימת־אב: https://github.com/rynrn/gonorth/issues/74.

## ממצא ופעולה

במהלך מחקר #93 נמצאה בסקיל gn-place דוגמת Authorization Basic עם ערך מוטמע. הדוגמה הוסרה, בלי לשמור או להציג את הערך. הסקיל מבהיר גם שרשומה חדשה נוצרת רק בסטטוס pending. בסקיל wp-security הוחלפו שתי דוגמאות מסוכנות: העברת סיסמה בפקודת shell והדפסת שורות מ-wp-config שעשויות להכיל מפתחות. כעת ההוראה היא להשתמש בחנות אישורים מאושרת ולקרוא רק דגלים שאינם סודיים.

לכלי tools/scan-secrets.py נוסף כלל לזיהוי Basic Auth מילולי. בדיקת ערך סינתטי אישרה זיהוי, ומחרוזת placeholder אינה מזוהה. הרצת הסורק על קובצי Git במצב הנוכחי החזירה No tracked credential patterns detected. זו אינה בדיקת תקפות אישורים, היסטוריית Git, עותקים אחרים או מאגר מרוחק.

## מפת אינטגרציות להמשך

| אינטגרציה | בעלות ידועה | הרשאה/תלות שצריך לאמת | מצב |
|---|---|---|---|
| SSH לשרת | חשבון אוטומציה claude; בעל השרת אינו מתועד כאן | מפתח SSH, הגבלת גישה, שחזור | לא סובב |
| WordPress REST/MCP | חשבון אתר rynrn במסמכי הפרויקט; בעל אנושי לא אומת | application password ייעודי והרשאות מינימליות | לא סובב |
| Google Places | מפתח מוגבל ל-IP שרת לפי הוראות הפרויקט | בעל חשבון Google, APIs וגבולות שימוש | לא סובב; אין מפתח זמין בסביבה שנבדקה |
| GitHub CLI | זהות gh מקומית | הרשאת repo וטוקן מקומי | לא סובב |

אין לקבוע שהאישור שהופיע בדוגמה תקף או חשוף ציבורית. לפני ביטול יש להקים חלופה ייעודית, לאמת אותה באותו נתיב עבודה ואז לבטל ולוודא כישלון של הישן; הטיפול בהיסטוריה ובעותקים מתואם בנפרד. לא בוצע שינוי באתר או בחשבונות.
