# Issue #100 — כל 22 המקומות הושלמו

תאריך: 2026-10-02

## תוצאה

כל 22 סעיפי הכרטיס קיבלו דף מקום תקין. נוצרו 18 דפים חדשים, שני דפים קיימים הועשרו, ושתי שורות הבניאס אוחדו בדף הקיים כדי למנוע כפילות. יש 21 כתובות ציבוריות ייחודיות, וכולן החזירו HTTP 200 ברגרסיה הסופית.

האצווה האחרונה כללה:

- TRIO — טריו קפה — ID 498, תמונה 504.
- שירי פסטה — ID 499, תמונה 505.
- קמפינג מטיילים דפנה — ID 500, תמונה 506.
- מלון מטיילים ארץ דפנה — ID 501, תמונה 507.
- קלומפוס — ID 502, תמונה 508.
- הטנק הסורי ההפוך — ID 503, תמונה 509.
- שמורת טבע הבניאס — ID 191 — עדכון תוכני שמכסה במפורש את מפל הבניאס, השביל התלוי והגשר התלוי.

## מקורות והחלטות

המקורות נבדקו ב־2026-10-02: Google Places; Travel Hotels עבור טריו, הקמפינג ומלון ארץ דפנה; העמוד הרשמי של שירי פסטה; האתר הרשמי של קלומפוס; ורשות הטבע והגנים עבור הבניאס והקשר המסלולי של הטנק. שעות משתנות לא הוזנו ללא מקור יציב. לכל ששת המקומות החדשים נבדקו שלוש תמונות Google ונבחרה תמונה שמציגה את המקום עצמו; נשמרו שם משאב, ייחוס, ALT ותאריך שליפה.

מפל הבניאס והשביל התלוי והגשר התלוי הם אותו מוקד בתוך שמורת הבניאס. שתי שורות הכרטיס ממופות ל־ID 191 ואין דף מתחרה.

## בקרות

- סיכון: L2.
- ממשק קנוני: WordPress ו־GoNorth_Place_Data::update; ללא SQL.
- snapshot מלא נשמר לבניאס ובדיקת כפילויות לפי שם ו־Place ID החזירה אפס התאמות לכל ששת המקומות החדשים.
- validate-place-records: שש רשומות, אפס שגיאות ואפס אזהרות.
- סקריפטי PHP עברו lint בשרת.
- כל הרשומות נוצרו תחילה ב־pending, עברו אימות קנוני ורק אז פורסמו תחת האישור המתמשך של בעל האתר.
- לששת הדפים החדשים נבדקו HTTP 200, canonical, RTL, תמונה וסמן תוכן.
- הבניאס נבדק בעקיפת מטמון: HTTP 200 והתוכן הציבורי כולל מפורשות את שלושת המונחים.
- רגרסיית מלאי מלאה: 21/21 כתובות ייחודיות החזירו HTTP 200.

ניסיון QA נוסף ב־Chrome נכשל בגלל תקלה מקומית של כלי הדפדפן לפני פתיחת הדף. לא נמצאה תקלה באתר; כל הדפים משתמשים בתבנית single-gd_place.php שכבר נבדקה באצוות הקודמות, ובדיקות הציבור וה־RTL עברו.
