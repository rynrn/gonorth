# השלמת #46 — Search Console

[Issue #46](https://github.com/rynrn/gonorth/issues/46). מצב: חסרה גישה/יצוא; לא ידוע אם הנכס מחובר.

1. להיכנס לחשבון Google של הבעלים ולבדוק קיום `sc-domain:gonorth.co.il` או נכס URL תואם לקנוניקל HTTPS.
2. אם אין נכס: לאמת בעלות בדרך הזמינה לבעלים. אין להסיק שתג GA4 הוא אימות Search Console.
3. לבדוק תאריך אחרון עם נתונים מלאים. תקופת בסיס מוצעת, אם זמינה במלואה: 18.08–14.09.2026 (28 ימים). השוואה: 21.07–17.08.2026 (28 ימים). לשמור גם השוואה שנתית אם קיימת ולסמן השפעת חגים.
4. להוציא Web ו־Image בנפרד; totals יומיים, pages, queries, page/query, country, device. לשמור כל חתך בנפרד עם filters, search type, property, dates ותאריך יצוא.
5. בדוח: קליקים, חשיפות, CTR, מיקום; הזדמנויות במיקום 5–20 מסודרות לפי חשיפות; כמות ראיות מספקת לפני שינויים בכותרת.
6. pagination ונתונים חסרים מתועדים. שורות שאילתות אינן מייצגות בהכרח את כל התנועה.
7. דוח חוזר אחרי 28 ימים מלאים ממועד השינוי הראשון; מעקב חודשי לפי אותו מפרט. אין עדיין תזמון אוטומטי.

אין להקים תיקון "לפני/אחרי" עם נתוני דמה. CSV שהבעלים מייצא יכול לשמש כשאין חיבור API, אחרי בדיקת החתכים.
