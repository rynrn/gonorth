# GoNorth.co.il

אתר תיירות בעברית לצפון ישראל, מבוסס WordPress ו־GeoDirectory.

## מידע משתנה על מקומות

מערכת האימות המקומית נמצאת ב־[`place-facts/`](place-facts/README.md). היא מנהלת ב־SQLite סטטוס פעילות, שעות, טלפון, כתובת ואתר; שומרת היסטוריית בדיקות; ומעבירה כל שינוי דרך ביקורת לפני סנכרון ל־WordPress.

תוכן עריכתי נשאר ב־WordPress. עסק סגור נשאר בעמוד חי עם הודעת מצב וחלופות לפי מדיניות ה־SEO של הפרויקט.
